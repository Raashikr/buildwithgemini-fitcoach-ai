# My agent: FitCoach AI (Fitness & Workout Coach)
One-liner: A conversational agent that helps fitness enthusiasts plan personalized routines and track progress with a catalog of exercises and workout plans.

Tool coverage:
- Memory: Remembers user fitness goals, target weight, past workout logs, fitness level, and active injuries or physical limitations across sessions.
- Tools: Look up exercise guides, log completed workout sessions, and fetch exercise recommendations.
- Catalog/UI: Exercise library (muscle groups, equipment needed, difficulty) and structured daily/weekly workout routines rendered as A2UI cards and tables.
- Image gen: Generates custom motivational workout posters and milestone accomplishment visuals.
- Sandbox: Calculates training heart-rate zones, 1RM (one-rep max) percentage progressions, total volume, and estimated caloric expenditure via code execution.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for training zone & 1RM calculations, Cloud Trace for observability
